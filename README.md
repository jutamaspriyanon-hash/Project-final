🎯 วัตถุประสงค์ของโครงการ (Project Objectives)
 * เพื่อสำรวจและทำความสะอาดข้อมูล (Data Cleaning & Preparation): ตรวจสอบและจัดการคุณภาพข้อมูลธุรกรรม e-Commerce ที่มีความซับซ้อน เช่น ค่าสูญหาย (Missing Values), รายการซ้ำซ้อน (Duplicate Records) และค่าติดลบ โดยรักษารหัสและโครงสร้างที่มีความหมายทางธุรกิจไว้ครบถ้วน
 * เพื่อวิเคราะห์พฤติกรรมการสั่งซื้อเชิงลึก (Sales & Customer Analytics): ค้นหาแนวโน้มยอดขายตามช่วงเวลา (Sales Trend), การจัดอันดับสินค้าขายดี (Top Performing Products) และการจำแนกสัดส่วนตลาดตามภูมิศาสตร์ (Geographic Segmentation)
 * เพื่อพัฒนาเว็บแสดงผลข้อมูลเชิงโต้ตอบด้วย D3.js (Interactive Web Visualization): พัฒนาเว็บแดชบอร์ดโดยใช้ D3.js ในการเรนเดอร์กราฟแบบ Dynamic และ Interactive เพื่อช่วยให้ผู้บริหารและทีมการตลาดสามารถเจาะลึกข้อมูล (Drill-down) เพื่อประกอบการตัดสินใจทางธุรกิจได้อย่างมีประสิทธิภาพ
🔗 ที่มาของชุดข้อมูล (Dataset Source & Details)
 * แหล่งที่มาของข้อมูล (Dataset Link): UCI Machine Learning Repository - Online Retail Dataset
 * ไฟล์ข้อมูลดิบ (Raw File): Online Retail.xlsx (อยู่ในโฟลเดอร์ /data/raw/)
 * ไฟล์ข้อมูลทำความสะอาดแล้ว (Cleaned File): Online Retail Cleaned.csv (อยู่ในโฟลเดอร์ /data/cleaned/)
 * รายละเอียดชุดข้อมูล: ข้อมูลธุรกรรมการซื้อขายจริงของบริษัทค้าปลีกออนไลน์ในสหราชอาณาจักร (United Kingdom) ครอบคลุมช่วงเวลาตั้งแต่เดือนธันวาคม ค.ศ. 2010 ถึง เดือนธันวาคม ค.ศ. 2011 รวมทั้งสิ้น 536,638 รายการ จาก 38 ประเทศ
 * โครงสร้างคอลัมน์หลัก:
   * Description: ชื่อ/คำอธิบายสินค้า
   * Quantity: ปริมาณสินค้าที่สั่งซื้อต่อรายการ
   * InvoiceDate: วันและเวลาที่เกิดธุรกรรม
   * UnitPrice: ราคาต่อหน่วย (ปอนด์สเตอลิง £)
   * CustomerID: รหัสประจำตัวลูกค้า
   * Country: ประเทศของผู้สั่งซื้อ
   * TransactionType: ประเภทธุรกรรม (Sale รายการปกติ / Return รายการยกเลิกหรือคืนสินค้า)
   * LineAmount: ยอดขายรวมต่อรายการ (\text{Quantity} \times \text{UnitPrice})
📊 รูปแบบการนำเสนอข้อมูลบน Web Dashboard (D3.js Visualization)
แดชบอร์ดพัฒนาด้วย D3.js ทั้งระบบ โดยถูกออกแบบให้รองรับการตอบสนองเชิงโต้ตอบ (Interactive Features) และแสดงผลแบบ Responsive บนทุกขนาดหน้าจอ ประกอบด้วย 3 ส่วนสำคัญ:
 * ส่วนตัวกรองข้อมูลหลัก (Global Filters Panel):
   * ตัวกรองประเภทประเทศ (All Countries / Specific Country)
   * ตัวกรองประเภทการซื้อขาย (Sale & Return / Sale Only / Return Only)
   * ตัวกรองช่วงเวลา (ปี และ เดือน)
   * ปุ่มรีเซ็ตตัวกรองทั้งหมด (Reset Filters)
 * ส่วนการแสดงผลตัวเลขชี้วัดหลัก (KPI Scorecards):
   * มูลค่ารายการรวมทั้งสิ้น (Total Revenue): £11,525,028.47
   * จำนวนชิ้นสินค้าที่จำหน่ายได้: 6,127,533 ชิ้น
   * จำนวนระเบียบรายการธุรกรรม: 536,638 รายการ
   * ขอบเขตประเทศที่มีการสั่งซื้อ: 38 ประเทศ
 * แผนภาพวิเคราะห์เชิงโต้ตอบ 4 รูปแบบ (Rendered by D3.js):
   * 🥇 Horizontal Bar Chart (D3.js): แสดงสินค้าขายดี 10 อันดับแรก (Top 10 Products) พร้อมสลับมุมมองระหว่าง "มูลค่ารายการ (£)" และ "จำนวนชิ้นสินค้า"
   * 🍩 Donut Chart (D3.js): แสดงสัดส่วนยอดขายต่างประเทศพร้อม Legend และ Tooltips โต้ตอบการวางเมาส์
   * ⚖️ Comparison Bar Chart (D3.js): เปรียบเทียบสัดส่วนมูลค่ารายการสั่งซื้อปกติ (Sale) กับรายการคืนสินค้า (Return)
   * 📈 Scatter Plot (D3.js): แสดงความสัมพันธ์ระหว่างราคาต่อหน่วย (UnitPrice) กับปริมาณสั่งซื้อ (Quantity) รองรับระบบ Zooming, Panning และ Dynamic Axes
